🐧 Configurações Linux / Flatpak & Brave

1. Se a API estiver desativada no Brave:

Abra a flag abaixo no Brave, marque "Enabled" e reinicie o navegador:

brave://flags/#file-system-access-api

2. Navegadores Flatpak no Linux (Bazzite, Fedora, etc.):

Execute no terminal para conceder acesso às pastas locais:

flatpak override --user --filesystem=home com.google.Chrome
flatpak override --user --filesystem=home com.brave.Browser
flatpak override --user --filesystem=home org.chromium.Chromium
flatpak override --user --filesystem=home com.microsoft.Edge

3. Modo Gráfico (Flatseal):

No Flatseal: selecione seu navegador → vá na seção Filesystem → ative All user files (home) ou informe o caminho da pasta.
